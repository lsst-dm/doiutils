### New features

- Add the ``create-dataset-bibs`` subcommand to generate BibTeX entries for the primary DOI and each dataset type DOI in a data release configuration.
  The ``--create-per-type`` option writes each entry to its own file in the current working directory (``dataset.bib`` for the data release and ``<variant>-<name>.bib``, such as ``butler-visit_image.bib`` or ``tap-Object.bib``, for each dataset type) for inclusion in the per-release documentation.
